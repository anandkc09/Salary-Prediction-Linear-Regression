# Salary Prediction Using Linear Regression

## 📌 Project Description

This project is a simple Machine Learning project that predicts an employee's salary based on their years of experience.

The project uses the **Linear Regression** algorithm.

---

## 📊 Dataset

The dataset contains the following features:

- **Age** - Age of the employee
- **Experience** - Years of work experience
- **Hours** - Working hours
- **Salary** - Employee salary

---

## 🤖 Machine Learning Model

This project uses:

- Linear Regression

### Input Feature

Experience

### Target

Salary

The model learns the relationship:

Experience → Salary

---

## 📈 Project Workflow

1. Import required libraries
2. Create and explore the dataset
3. Visualize the data
4. Select Experience as the input feature
5. Select Salary as the target variable
6. Split the dataset into training and testing data
7. Train the Linear Regression model
8. Predict salary using the trained model
9. Evaluate the model using Mean Absolute Error (MAE)
10. Predict salary for a new employee
